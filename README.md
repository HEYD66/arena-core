# 千面 Facet 0.2.0

> 原名 Arena Core。改名只影响显示名称和图标；数据目录仍是 `%APPDATA%\ArenaCore`，项目文件夹和内部会话分区名不变，已有实例、会话和设置全部保留。

独立的精简核心项目：真实浏览、多实例持久会话、可配置实例环境、显式本机 IP 直连和应用自带 Mihomo。旧程序与旧 app.asar 不修改、不复用数据。

## Windows 启动

需要 Node.js 22.12+。在此项目目录执行：

日常可双击项目目录里的 **Facet.lnk**（千面图标）。它只用系统 `cmd.exe /d /c` 调用本项目已审阅的 `start.cmd`，启动终端最小化；不改用户数据，不自动启动实例。快捷方式含绝对路径，移动项目后可重新生成：在项目目录执行 `node scripts/create-shortcut.cjs`。这是本机专用入口，不是已签名安装器。

“打开文件 - 安全警告”属于 Windows 启动前的检查，不是应用弹窗；来源标记和系统策略都可能影响它。不要全局关闭安全检查或将所有 `.cmd` 加入低风险白名单。本次检查 `start.cmd` 未发现 `Zone.Identifier`；新增快捷入口不等于确定原警告的原因。

启动器会先验证 Windows Electron 版本。若原路径在进入主进程前发生 `0x80000003`，会将同版本运行时复制到 `%LOCALAPPDATA%\FacetRuntime\electron`，逐文件校验并再次自检后启动；缓存按文件内容区分版本。项目仍在原位置，用户数据仍在 `%APPDATA%\ArenaCore`，不会自动启动实例、关闭沙盒或停用其他软件。此路径回退源于本机 D 盘失败 / C 盘成功的对照，不代表已确定底层驱动或系统策略原因。缓存通常约 350 MB，可在完全退出 Facet 后删除，后续需要时会重新生成。显式设置 `ELECTRON_OVERRIDE_DIST_PATH` 时尊重开发者指定的运行时，不自动替换。

```powershell
npm ci
npm run setup:core
npm start
```

`setup:core` 仅从官方固定发行版下载本应用自己的 Mihomo，校验压缩包 SHA256 后解压，附带 LICENSE、对应 tag 源码归档及 ARTIFACT.json。若仅使用直连，可以跳过内核安装。不会寻找或调用 Clash Verge 等其他客户端。

## 使用

1. 默认主实例处于停止状态；点击“启动当前实例”，没有节点也可使用 **本机 IP 直连**。
2. 顶部 + 新建实例，每个实例有独立持久会话。切换标签不会停止其他实例。
3. 地址栏输入 HTTP/HTTPS 网站，支持前进、后退、刷新；弹窗网站的新链接在同实例内打开，不启动外部浏览器。
4. 在左下“全局管理 → 代理管理”保存多个 Clash/Mihomo HTTP(S) 订阅或本地 YAML/JSON（最多 30 个源）。每个源可改名、替换链接、手动更新、删除；节点支持搜索、分页。选定目标实例后“分配”节点，确认后只停止该实例并设置代理模式，再自行启动。各实例独立使用不同节点，仍可在“代理与指纹”明确切回本机直连。
5. 全局导入、更新或删除不会停止实例，也不自动替换已分配的节点副本。需要使用更新后的节点时重新分配；分配或保存实例环境会停止目标实例。代理缺少节点、内核缺失、启动失败时会明确报错；**不会自动切换直连**。
6. 关闭标签：停止实例，保留配置和登录存储。删除实例：停止并清除该实例 Cookie/网站存储及配置，需单独确认。

删除先停止实例并提交配置删除，再清理浏览数据与节点文件。配置写入失败不会清空浏览存储；配置已删除但清理失败时会明确提示，残留文件与扩展绑定在下次启动重试。此机制不提供已删除登录资料的撤销恢复，也不保证断电时的事务持久性。网络配置只接受 `direct` / `mihomo`；读取、创建或启动时发现非法配置会拒绝操作，保留原配置文件，不自动改为直连。

7. 应用退出会等待其创建的内核退出；再次打开不会自动启动实例。有运行或启动中的实例时显示跟随当前主题的确认窗口；默认聚焦“取消”，Esc / 右上角 × 均取消，只有“停止并退出”才继续。“不再提示”仅在确认退出后保存；取消不会更改偏好。

## 指纹环境的具体范围

每实例设置语言、区域和 IANA 时区；高级设置可覆盖 UA、navigator.platform、视口/屏幕尺寸、像素比、navigator.hardwareConcurrency、色彩/动画偏好以及可选固定定位。默认保留原生值。通过 CDP 在首次外部页面加载前应用；UA/platform 自定义时清空 UA-CH 元数据以避免继续发送矛盾的原生信息，但可能影响网站兼容性。没有 Canvas、GPU、字体、deviceMemory 或 webdriver 伪装脚本；不是更换物理设备，也不承诺匿名、防识别或风控绕过。

代理只改变网络路由，不保证不同节点对应不同公网 IP。WebRTC 防护在 `web-contents-created` 阶段调用 Electron 原生 `setWebRTCIPHandlingPolicy('disable_non_proxied_udp')` 并核验读回值，不再依赖本机实测未生效的同名全局启动参数。实例、弹窗和扩展窗口均在页面脚本运行前设置；设置失败会关闭新页面，无法安全关闭则退出进程，不静默退回默认策略。QUIC 仍禁用。

此防护阻止非代理 UDP，并非伪造 IP，也不保证 WebRTC 一定显示 HTTP 出口 IP；无法建立受允许连接时可能没有 ICE 候选，网页语音、视频会议和 P2P 功能可能受影响。TURN 中继地址也可能与 HTTP 出口不同。`npm run test:webrtc` 使用临时配置、本机 HTTP 代理和模拟 STUN，包含旧行为正对照、弹窗首段脚本、跨站 iframe 与会话存储隔离；不访问真实节点或账号。Windows Electron 44.4.5 的受控测试通过，不等于完整 DNS / IPv6 / 实际节点泄漏验收。

升级后需保存工作、完全退出千面，再通过 `start.cmd` 重开，随后启动目标实例并重新检测；仅刷新网页或在旧进程内重启实例不会加载新的主进程代码。不会清除现有 Cookie 或账号数据。

## 数据

Windows 数据目录：`%APPDATA%\ArenaCore`。

- `workspace-tools.json`：节点收藏引用与 IP 地址备忘（不复制节点密码），跨重启保存。
- `global-events.json`：最近1000条脱敏日志，自动淘汰旧记录；导出前仍应自行审阅。
- `instances.json`：实例 ID、名称、最近网址、环境和网络模式。
- `Partitions/`：Electron 各实例持久会话。
- `proxy-library.json`：全局多订阅及本地节点库，**含明文订阅链接和节点凭证**；切勿分享。
- `diagnostic-runtime/`：临时诊断核心，检测结束后清理。检测结果仅本次应用运行保留。
- `proxy-sources/`：用户导入的节点配置和已保存的订阅链接，**可能含订阅令牌和代理凭证，存于本机，尚未加密**。不提交、不分享此目录。
- `core-runtime/`：独立内核数据和临时运行配置；进程确认退出后删除运行配置。

权限默认拒绝（摄像头、麦克风、地理位置等）；只有显式启用固定定位的实例允许地理位置权限并返回配置坐标；远程页面没有 Node 和管理 IPC。控制界面与网页进程隔离。正常网页自身的网络请求属于用户浏览，控制界面 CSP 不允许外部连接。

## 订阅导入

在“全局管理 → 代理管理”输入名称与链接，点击“导入并保存订阅”。多个订阅分别保存和更新；编辑时链接留空只改名，填写新链接则下载并替换该源。下载或解析失败保留旧配置。首次升级会把旧实例已保存的节点源复制到全局库，相同订阅链接去重；不修改旧实例文件。更新或删除全局源不会影响已分配副本，需重新分配才能应用新节点配置。

订阅需直接返回包含 `proxies` 数组的 Clash/Mihomo YAML/JSON。通用 Base64 URI 列表、登录网页、仅含 proxy-providers 的配置暂不支持；请从服务商获取 Clash/Mihomo 专用链接。下载通过本机直连，不读取其他代理客户端，不经过第三方转换器。HTTPS 正常校验证书，拒绝重定向降级为 HTTP；HTTP 链接本身不加密，请优先用 HTTPS。20 秒总超时、最多 3 次重定向、传输与解压后的内容均限制 2MB。

界面只显示来源主机名和更新时间，不显示已保存的完整链接；输入默认隐藏，状态/日志不返回订阅令牌。原始链接仍为明文保存于本机用户目录，切勿分享该目录。

## 手动代理检测

- 单节点或批量（每次最多 100 个，默认3路并发，可调1–6路）连通性/延迟与出口 IP 查询，可取消。
- Cloudflare HTTPS 首响应耗时包括连接/TLS，不是 ICMP Ping；连通性失败时最多尝试一次 Google generate_204 备用目标；ipwho.is 提供出口 IP、国家/地区/城市与 ISP，地理信息仅供参考。
- 下载测速仅手动单节点执行，经 Cloudflare 下载 5,000,000 字节（约 5 MB，另有协议开销），显示 Mbps、耗时和下载字节数。短时结果不代表峰值带宽。
- 检测会访问以上第三方服务，它们可看到对应代理出口 IP。开始前有确认，不在启动时自动测速。
- 每个并发工作队列使用各自的临时 Mihomo 和不持久化的专用 Electron 代理会话，不复用实例 Cookie，不修改实例路由。只允许一个检测任务，失败不回退直连；服务异常也可能导致失败。
- 单次连通性尝试约12秒，含备用尝试最多约24秒；IP查询约20秒；下载测速约35秒（均不含最终清理）。取消可中断启动检查和请求，并回收全部工作队列的核心。

## 代理管理界面与节点删除

订阅输入区保持完整展开，页面整体滚动；节点表单独滚动。顶部固定显示检测任务进度和取消按钮，任务运行时禁用重复检测入口。

勾选节点后可“删除已选”，每行也提供“删除”。节点删除采用本地持久排除：从可用列表移除，订阅更新仍保持隐藏，可在订阅源卡片点击“恢复已删节点”撤销；不会删除实例已经分配的副本，也不会修改服务商订阅。删除整个订阅源是另一项独立确认操作。

导入订阅可填写自定义名称，留空时使用链接主机名；输入链接默认隐藏。

订阅导入、来源编辑/更新/删除，以及当前来源的节点选择、删除、恢复和分配，统一放在“订阅与本地节点源”卡片内；检测结果直接显示在对应节点行的连通性/延迟、出口 IP 和下载速度列；各类结果分别保留，悬停显示地区、错误详情及检测时间。

## IPv6 与连接错误

内置 Mihomo 允许 IPv6 解析与连接，不再全局固定关闭 IPv6；控制接口和浏览器代理入口仍只绑定 127.0.0.1。IPv6 节点仍要求主机具备相应公网路由，启用配置不能创造 IPv6 出站能力。当前 DNS 沿用系统解析，可能与其他 Clash 客户端配置不同。

内核输出只转换为固定错误分类（DNS、路由、证书、认证、拒绝、超时、握手、重置），不保存或显示原始日志、节点地址或凭证。页面错误可附加近期内核提示；检测失败显示安全分类，不能从一次检测失败直接认定节点无效。

## 订阅收纳、筛选与收藏

每个订阅为可折叠组，节点管理放在对应组内；当前展开管理一个来源，其他来源可保持收起。标题显示候选节点数、提示数、收藏数与最近检测概况。支持名称搜索、按名称/延迟/收藏排序、仅收藏/最近连通成功筛选。检测结果带时间，只代表上次结果，不保证当前可用。

“剩余流量、套餐到期”等疑似提示条目按名称启发式识别，保留原数据并默认不参加检测。误判时可点击“作为节点启用”，不是根据名称判定节点永久不可用。

订阅更新显示新增/移除/配置变化数量。新分配实例记录来源引用和节点副本，未启动页显示同步状态；旧版本没有来源引用的实例显示未关联，不猜测来源、不改动旧数据。来源变更或删除后不自动切换实例。检测中若来源更新，旧结果标记需要重测。

节点表 ☆ 收藏节点，IP结果旁“＋收藏”保存地址备忘；代理管理右上角统一“收藏夹”可测速、分配、定位节点、查看已分配实例及管理IP备注。节点与IP备忘各最多500条。IP备忘本身不是代理配置，也不能锁定线路出口。

## 全局日志与诊断摘要

全局管理新增“全局日志”，按级别、范围、实例筛选，搜索事件、节点或任务ID。记录应用、实例、订阅操作和检测任务；记录固定错误类别，不保存原始内核日志、网页内容、订阅链接或密码。日志写盘失败在页面警告，内存记录继续保留。支持导出JSON和复制脱敏诊断摘要（含应用/内核版本、配置类别和近期事件，不含完整UA、网址、节点凭证）。

## 高级环境的使用边界

| 参数 | 范围 / 行为 |
|---|---|
| 语言、时区 | 四种现有语言；有效IANA时区 |
| UA / platform | UA最多512字符；platform原生/Win32/MacIntel/Linux x86_64；有一致性提醒 |
| 视口 / 模拟屏幕 | 宽640–3840、高480–2160，必须同时设置；0/0自适应 |
| 像素比 | 0原生，或1–3 |
| CPU线程信息 | 0原生，或1–64整数；只是浏览器暴露值，不改变真实CPU |
| 媒体偏好 | 色彩system/light/dark，动画system/reduce/no-preference |
| 固定定位 | 默认关闭；启用后允许网页获取设置的经纬度，不改变IP地址或时区 |

提供恢复默认、日语/东京、英语/UTC预设，以及复制其他实例环境。填入后仍需明确保存；不会自动改网络模式。GPU/Canvas/字体/内存等保留真实，WebRTC非代理UDP限制始终保留。

未启动实例页面显示实例状态、节点来源与同步状态、最近检测IP（非实时）、环境摘要及最近错误。运行状态仅代表内核/浏览视图存在，网页加载状态另行显示。

## 参考指纹（可选、实验性）

环境 → 高级环境设置 → 参考设备与固定随机：6套Windows设备预设，或一键随机生成UA/平台、CPU/媒体偏好、设备模板与固定种子，并同时开启指纹总开关及 Canvas、音频、WebGL 三项覆盖。随机保留原视口、DPR和屏幕尺寸。按钮只填表，保存后停止目标实例，重新启动生效；不会改其他实例。随机不会改语言、时区或固定定位。已保存种子在刷新和重启后保持，只有再次点击随机才重抽。复制环境也复制种子，如需独立组合请重新随机。

独立开关：屏幕/可用高度/色深、设备内存与触摸点报告值、WebGL厂商/渲染器、Canvas读取与导出扰动、音频采样扰动、元素/Range边界矩形扰动。默认关闭参考覆盖；点击一键随机会在表单中开启总开关和 WebGL/Canvas/音频覆盖，保留基础硬件报告值及布局开关原状（布局默认关闭）。仅填入指定设备预设仍保留这三项原有开关。既有实例配置不会自动迁移。音频扰动会修改底层采样；布局扰动可能影响定位和截图；启用后如网页异常请关闭并重启实例。

支持状态：UA、语言、时区、视口/DPR、CPU、媒体偏好、固定定位通过CDP覆盖；额外硬件/图形项仅部分页面API覆盖，不是完整内核或硬件模拟。Worker、OffscreenCanvas、跨进程iframe等没有完整覆盖保证。字体、真实GPU、TLS、webdriver与媒体设备ID未伪装；不全局改写Function.prototype.toString，也不把参考中的addIceCandidate过滤当作防泄漏措施。摄像头/麦克风权限仍拒绝，自定义UA沿用清空UA-CH的兼容性策略。

参考归档 `指纹参考` 保持只读，未把旧注入脚本与新版重复加载；语言/时区/UA等只由主进程CDP负责。新增模块来自参考的模板与Canvas/音频/布局算法，增加字段校验、独立开关和受控注入；正式发行前仍需核查参考代码及所有依赖的授权。

## 按出口IP设置时区

新建实例可选本机直连或全局库中的节点副本，勾选“按所选出口IP设置一次时区”后，创建时查询ipwho.is并保存有效IANA时区；不会每次启动查询。代理查询使用临时独立Mihomo与隔离会话，失败不回退直连。查询失败仍创建实例，保留默认时区并记录警告。IP服务结果可能不准确，不推断国家的唯一时区。
