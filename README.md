# 千面 Facet

**面向 Windows 的开源多实例浏览器。** 在一个工作台中管理独立浏览会话、环境配置、代理节点与浏览器扩展，通过实时宫格集中查看多个网页。

[下载最新版](https://github.com/HEYD66/arena-core/releases/latest) · [版本记录](https://github.com/HEYD66/arena-core/releases) · [反馈问题](https://github.com/HEYD66/arena-core/issues)

如果千面对你有帮助，欢迎点一下 **Star**，帮助更多人发现这个项目。

## 功能

| 功能 | 说明 |
| --- | --- |
| 独立浏览会话 | 各实例拥有独立的 Cookie、网站存储和登录状态，关闭后保留，重新启动可继续使用 |
| 实例管理 | 创建、重命名、启动、停止及批量操作；顶部标签支持滚动查看 |
| 实时宫格 | 多个网页同时实时加载，支持放大查看；另提供省资源模式，由用户选择 |
| 环境配置 | 配置语言、区域、时区和浏览环境参数，支持一键随机生成配置草稿，再确认保存 |
| 代理管理 | 导入订阅、Clash/Mihomo 配置及常见单节点格式，支持测速、查询出口 IP 和切换节点 |
| 浏览器扩展 | 导入解压扩展，按实例管理启用状态；提供扩展更新检查与弹窗支持 |
| 收藏与音量 | 网页书签、快捷入口、节点与 IP 收藏，以及实例音量和静音控制 |
| 外观主题 | 多套日间与夜间配色，默认「日光 / 黑金」，主题选择跨重启保存 |
| 软件更新 | 每次启动自动检查一次 GitHub 新版本，同一版本只主动提醒一次；下载及安装由用户确认 |
| 日志与诊断 | 系统日志、实例运行日志、运行输出和网络诊断，便于定位问题 |

当前支持 Windows x64，最多创建 15 个实例。实时模式的资源需求随运行实例数量和网页内容增加。

## 下载安装

1. 打开 [最新版发布页](https://github.com/HEYD66/arena-core/releases/latest)。
2. 下载 `Facet-Setup-<版本>-x64.exe`，运行安装向导。
3. 安装后启动「千面 Facet」，点击「启动当前实例」开始使用。

安装包自带 Electron、Mihomo 和进程保护组件，**无需安装 Node.js**。支持选择安装目录，并创建桌面与开始菜单快捷方式。建议使用默认 C 盘目录。

安装包目前**未签名**，Windows 可能显示发布者或安全提示。请从本仓库 Releases 下载；每个版本附带 `.sha256` 校验文件。

```powershell
Get-FileHash "下载的安装包绝对路径" -Algorithm SHA256
```

## 快速使用

- **新建实例**：点击顶部 `+`，填写名称，选择本机直连或代理节点，按需设置环境。
- **配置环境**：进入「环境配置」，编辑或一键随机后确认保存。保存会停止目标实例，随后手动启动。
- **添加代理**：进入「代理管理」导入订阅或节点，测速并查询出口 IP，再分配给实例。
- **查看宫格**：进入「宫格总览」，选择实时模式或省资源模式；放大后可返回宫格。
- **导入扩展**：进入「扩展中心」，选择包含 `manifest.json` 的解压扩展目录，确认权限后导入，再按实例启用。
- **调整主题**：进入「主题设置」分别选择日间和夜间配色，通过顶部按钮切换。

关闭实例标签会停止该实例并保留登录资料。删除实例会清除该实例的配置与浏览存储，需要单独确认。退出应用会正常停止其运行实例；再次打开应用不会自动启动实例。

代理节点和订阅由用户提供。代理配置失败时会显示错误，不会自动切换为本机直连。全局节点库更新后，已分配给实例的节点副本需重新分配才能更新。

## 软件更新

从 **0.2.3** 起，Windows 安装版在启动约 10 秒后自动检查一次更新，运行期间不定时轮询。发现更高的稳定版本时显示顶部提示；同一版本的提醒记录保存在本机，重启后不重复提醒。关闭提示后仍可通过顶部「有更新」或「应用信息 → 软件更新」查看新版。

更新不会自动下载、停止实例或安装。点击「下载新版」，下载校验完成后选择「退出并更新」，确认后正常停止实例、退出并安装，保留实例配置、登录资料与扩展。

- 0.2.1 / 0.2.2 可通过「应用信息 → 软件更新」手动检查更新。
- 更早版本请手动安装当前最新版。
- 使用默认数据目录时，更新后会重新打开应用，实例需手动启动。
- 使用 `--user-data-dir=绝对路径` 时，更新后请通过原入口启动，以保持同一数据目录。
- 无法访问 GitHub 时，自动检查不弹出错误提示，可在应用信息中查看状态并手动重试。

更新源是本项目的公开 GitHub Releases，不要求用户提供 GitHub Token。更新清单使用 SHA512 校验下载文件；草稿与预发布版本不作为正式更新。

## 数据与隐私

实例资料和配置保存在本机：`%APPDATA%\ArenaCore`。升级沿用该目录，卸载默认保留资料。

| 位置 | 内容 |
| --- | --- |
| `instances.json` | 实例名称、最近网址、环境与网络配置 |
| `Partitions/` | 实例与控制界面的持久浏览存储 |
| `proxy-library.json`、`proxy-sources/` | 代理库和来源配置，可能包含订阅令牌、节点密码 |
| `workspace-tools.json` | 收藏与工作区工具配置 |
| `app-settings.json` | 退出确认偏好及已提醒的更新版本 |
| `global-events.json`、`runtime-output.json` | 系统日志与运行输出 |

**不要分享整个数据目录。** 代理凭据在本机配置中可能以明文保存；导出资料和日志前请检查敏感信息。安装包不包含开发者账号、代理节点或个人扩展资料。

自动更新检查会访问 GitHub；订阅、测速、IP 查询及网页访问会联系各自的服务。千面不提供代理服务，也不上传本机实例配置与登录资料。

## 环境配置说明

环境设置用于区分实例的浏览参数，可能影响网站兼容性。部分高级覆盖会改变网页读取的图形、音频或布局结果，遇到异常可关闭相应选项并重启实例。

WebRTC 使用限制非代理 UDP 的策略，可能影响网页语音、视频会议或 P2P 功能。代理、环境覆盖和 WebRTC 设置都不保证匿名、防检测或完全无泄漏。千面不提供自动注册、系统代理或 TUN 功能。

## 源码开发

技术栈：**Electron + JavaScript + WebContentsView + Mihomo**。控制界面和实例网页进程隔离；远程网页不具备 Node.js 或管理 IPC 权限。

需要 Windows x64 和 Node.js 22.12+：

```powershell
npm.cmd ci
npm.cmd run setup:core
npm.cmd start
```

只使用本机直连时可跳过 `setup:core`。该脚本从官方固定版本获取 Mihomo，并校验来源和文件哈希。日常也可使用项目内的 `start.cmd` 启动；开发运行不执行安装版在线更新。

| 目录 | 用途 |
| --- | --- |
| `src/main/` | 实例生命周期、会话、代理、环境、扩展、IPC 和更新 |
| `src/renderer/` | 控制界面、宫格、主题、表单及交互 |
| `resources/` | 图标、Mihomo 发行资源和进程保护组件 |
| `scripts/` | 启动、检查、构建与发布脚本 |
| `tests/` | 单元、界面及真实 Electron / 安装包验证 |
| `docs/` | 专项设计和验证资料 |

### 验证与构建

```powershell
npm.cmd run check
npm.cmd run test:updates
npm.cmd run test:packaging
npm.cmd run test:core
npm.cmd run build:process-host
npm.cmd run build:installer
```

安装包和校验文件生成在 `release/`。真实安装版测试使用独立数据目录，可运行：

```powershell
npm.cmd run test:installed -- "安装目录\Facet.exe"
node tests/theme-installed.cjs "安装目录\Facet.exe"
node tests/github-update-installed.cjs "安装目录\Facet.exe"
```

Electron 验证使用本机页面和临时数据；具体测试是否使用模拟 IPC，以测试文件的说明为准。测试结果不能替代真实节点和所有网页的兼容性验证。

### 发布新版

递增版本，同步 lockfile，完成验证及构建后提交、推送代码，再上传 Release：

```powershell
npm.cmd version patch --no-git-tag-version
npm.cmd run check
npm.cmd run test:updates
npm.cmd run build:installer
# 提交并推送代码后，传入本次更新说明文件
npm.cmd run release:publish -- notes.md
```

发布脚本校验版本、安装包与清单，在草稿中上传安装包、`.blockmap`、`latest.yml` 和 `.sha256`，确认文件完整后公开发布。仅提交代码不会产生客户端可下载的更新。
