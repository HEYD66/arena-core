# 千面 Facet 0.2.5

面向 Windows x64 的开源多实例浏览器。安装包内置运行环境，无需安装 Node.js。

## 本次更新

- 安装路径：新安装默认 `D:\Facet`，无可访问 D 盘时使用 `C:\Facet`；修改位置自动补上 `Facet` 子文件夹，实际安装时创建。升级保留原安装路径。
- 实例管理：增加批量选择和删除，支持为每个实例设置“随应用启动”，设置跨重启保留。
- 环境同步：根据所选代理出口同步时区和语言，批量创建使用对应出口信息。
- 出口查询：优先 IP.SB，支持服务回退与请求频率控制。
- 快捷入口：`ipip.la` 排在第一位，新实例默认打开检测页面。
- 更新提醒：主界面加载后立即异步检查一次，发现新版弹窗提醒；同一版本不重复主动提醒。下载和安装仍由用户确认。
- 实时宫格：增加“全部 / 正在运行”筛选，调整实例管理顶栏位置。
- 运行标签：顶部仅显示运行实例，重启实例后恢复对应标签。
- 系统日志：合并操作记录和调试输出，记录真实实例启停事件，加入 GitHub 问题反馈入口。

## 下载与更新

下载 `Facet-Setup-0.2.5-x64.exe`。安装包未签名，发布文件提供 SHA256 校验值。现有安装版可通过“应用信息 → 软件更新”检查、下载并确认安装。

升级前正常退出应用，保留实例配置、登录资料与扩展。新安装的 D 盘默认规则不会迁移现有安装或用户数据。

## 验证

安装路径和目录创建已在 Windows Sandbox 中验证，D 盘规则使用实际可访问的映射盘验证；正式安装、配置持久化和重启流程已验证。实际可同时运行的实例数量仍取决于硬件和网页负载。
