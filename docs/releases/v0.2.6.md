# 千面 Facet 0.2.6

面向 Windows x64 的开源多实例浏览器。安装包内置运行环境，无需安装 Node.js。

## 本次更新

- **实例导出与导入**：备份 Cookie、网站持久存储、环境配置和备注。默认每个实例一个 `.facetbackup` 文件，文件名包含实例名、日期时间（毫秒）和防重后缀；也可合并为一个文件。
- **多文件导入**：支持一次选择多个备份文件，单实例备份和合并备份可一起导入；为每个实例单独选择代理或直连，显示已有出口国家记录及来源文件。重名自动加后缀，导入创建独立的新实例。
- **导出不重启应用**：仅暂时停止所选实例，其他实例继续运行。未选择删除时，完成后恢复之前运行的实例；出口国家使用已有记录，不重新联网检测。
- **可选导出后删除**：默认关闭。所有备份生成、校验并成功保存后才删除所选原实例；导出失败保留全部原实例，文件名冲突不覆盖已有备份。部分文件已保存时会提示实际状态。
- **实例备忘录**：新增自由编辑的多行备注，随备份迁移。实例名称右侧提供备注按钮，列表不展示备注正文。
- **先导入、再同步环境**：可按新出口同步时区和语言；检测失败不撤销已导入数据，保留原环境并提示稍后处理。

## 下载与更新

下载 `Facet-Setup-0.2.6-x64.exe`。安装包未签名，附带 SHA256 校验文件。现有安装版可通过启动时的更新提醒，或“应用信息 → 软件更新”检查、下载并确认安装。

升级前正常退出应用。升级保留既有安装位置、实例配置、登录存储和扩展。

## 备份范围

备份没有密码保护，请妥善保管。包含 Cookie、网站持久存储、IndexedDB、缓存存储、网站文件、环境配置与备注；不包含浏览器保存的密码、插件程序及启用绑定、原代理凭据、未提交的网页内容和进程内存。

两端需使用相同操作系统和浏览器版本。导入后实例默认停止；设备、IP或凭据有效期变化可能要求网站重新登录。没有保证所有网站的登录状态可跨设备继续使用。

## 验证范围

分文件与合并导出、多文件混合导入、取消、写入失败、归档损坏、文件名冲突、校验后删除，以及导入后重启持久化均已通过实际测试。最终打包程序的原生文件夹选择、多文件选择、Cookie、网站数据和备注恢复已验证。

尚未在另一台设备或独立 Windows 账号实测迁移。本次没有重复进行 Windows Sandbox 安装向导测试。
