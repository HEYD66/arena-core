# 千面 Facet 0.2.7

面向 Windows x64 的开源多实例浏览器。安装包内置运行环境，无需安装 Node.js。

## 本次更新

- **实例音量操作**：宫格和放大实例窗口的音量图标支持左键静音、右键展开音量控制；各实例独立保存音量。
- **创建实例复用检测结果**：优先使用代理管理中已有的出口地区记录，无完整记录时参考节点名称识别地区。节点选择显示已有出口 IP、连通性、延迟及记录时间，减少重复查询。仅能识别国家、无法确定时区时保留原时区并提示。
- **最近连通性竖柱图**：每根柱代表一次检测，显示最近 10 次真实记录，左旧右新，成功绿色、失败红色；点击查看检测时间、延迟和失败原因。未检测的节点不生成柱，取消的检测不计入历史。
- **保留最新失败状态**：应用重启后正确显示最新一次检测失败及历史记录。
- **操作提示不再被遮挡**：提示显示在标签栏下方，网页与实时宫格随提示出现和消失调整可用区域，修复底部只露出提示边缘的问题。

## 下载与更新

下载 `Facet-Setup-0.2.7-x64.exe`，附带 SHA256 校验文件。现有安装版可通过启动时的更新提醒，或“应用信息 → 软件更新”检查、下载并确认安装。

升级前正常退出应用。升级保留既有安装位置、实例配置、登录存储和扩展。安装包未签名。

## 验证范围

本轮修复已通过真实网页、HTTP 代理及内置 Mihomo 检测、独立实例音量操作、实时页面提示布局和应用重启持久化验证。正式发布包另行检查资源完整性、更新清单校验值及打包程序的历史图展示与重启恢复。

已有检测记录不代表节点当前实时状态；批量创建与手动环境同步仍可执行联网查询。本次未重复 Windows Sandbox 安装向导测试。
