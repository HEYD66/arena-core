# 千面 Facet 0.2.8

面向 Windows x64 的开源多实例浏览器。安装包内置运行环境，无需安装 Node.js。

## 本次更新

- **扩展弹窗识别实例网页**：修复扩展面板打开后将自身误认为活动标签页的问题。活动标签页查询绑定到所属实例，多个实例分别操作，不互相串用。
- **首次源码启动自动准备依赖**：`start.cmd` 检查缺失依赖并自动按锁文件安装；依赖齐全时直接启动。源码用户仍需 Node.js 22.12 或以上版本，首次安装依赖需要网络。安装版用户无需此步骤。

本版本不包含实例操作同步器。浏览器扩展本身无需修改。

## 下载与更新

下载 `Facet-Setup-0.2.8-x64.exe`，附带 SHA256 校验文件。已有安装版可通过启动更新提醒，或“应用信息 → 软件更新”检查、下载并确认安装。

升级前正常退出应用。升级保留既有安装位置、实例配置、登录存储和扩展。安装包未签名。

## 验证范围

扩展活动标签页、原生消息调用、多实例隔离、设置保存与重载已通过真实扩展窗口验证。原版 Arena Model Probe 2.4.1 的面板识别和设置保存已验证，未执行真实聊天或抽卡。

首次源码启动已在无依赖目录完成真实安装与启动验证。正式发布程序另行验证扩展操作、实例隔离及应用重启后的网页数据和扩展绑定，检查安装包及更新清单完整性。

Electron 仅支持部分 Chrome 扩展 API；本次修复不代表兼容全部浏览器扩展。本次未重复 Windows Sandbox 安装向导测试。
