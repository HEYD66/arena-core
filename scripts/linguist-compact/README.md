# Linguist 简洁面板

为用户提供的 Linguist 7.1.0 解包目录生成独立副本。保留原翻译引擎、离线资源、LICENSE、DOLA 桥接及完整高级界面，不修改千面宿主代码。

## 使用

```powershell
node scripts/build-linguist-compact.cjs '原插件目录' '新的输出目录'
```

输出目录必须不存在。构建器校验版本和精确代码结构，核对原目录前后 SHA256；不支持的版本直接拒绝构建。

在千面扩展中心停用旧版 Linguist，然后添加生成目录，按实例启用。避免在同一实例同时启用两份翻译器。更多菜单保留高级设置和完整面板。

## 开关

- 默认开启，按实例的独立扩展存储保存状态。
- 关闭后恢复该实例的原文，暂停页面自动翻译和划词翻译，移除翻译右键菜单。
- 关闭时新页面不启动翻译引擎；重新开启恢复原配置和语言规则。
- 原始 `appConfig` 不因关闭开关而改写；关闭期间暂时停用高级入口。
- “始终翻译”规则只保存实际检测到且引擎支持的语言，用于后续页面及重新启用。

新增配置位于扩展自己的 `storage.local`：`facetTranslationEnabled`、`facetAlwaysLanguages`、`facetSimpleTarget`、`facetSimpleSource`。

## 真实验收

```powershell
node tests/linguist-compact-packaged.cjs '适配 Linguist 的 Facet.exe' '生成插件目录' '报告输出目录'
```

测试使用独立临时用户目录和真实本地英文页面，调用原在线翻译引擎，核对真实中文译文、闭合 Shadow DOM 内的划词译文、关闭行为、实例隔离、完全退出重启后的持久化和更多菜单实际点击。测试没有替换翻译接口；联网翻译不可用时应报失败。测试进程单独关闭原生窗口遮挡检测以避免测试窗口被其他应用遮挡后暂停绘制；生产程序不改变此配置。

千面需要已有 Linguist 接口适配版本；未修改的其他 Electron 宿主不保证兼容。此轮没有全面复验离线模型、语音朗读、自定义翻译引擎和原 DOLA 功能。

## 回滚

停用简洁副本，重新启用保留的原版目录。构建脚本、模板和验收脚本独立于千面主程序，可用 Git 恢复。用户的实例数据和原插件目录不参与删除或迁移。
